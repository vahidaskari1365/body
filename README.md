# فیت‌کوچ (FitCoach) 🏋️

پلتفرم آنلاین مدیریت ارتباط مربیان ورزشی و ورزشکاران — نسخه دمو (MVP کامل و قابل استفاده)

مربی می‌تواند تمام فرآیند کاری خود با ورزشکاران را در یک سیستم مدیریت کند و ورزشکار از طریق حساب کاربری خود به برنامه‌ها و اطلاعات تمریناتش دسترسی دارد.

---

## ⚡ شروع سریع

```bash
# 1) نصب وابستگی‌ها
bun install

# 2) دیتابیس (SQLite + Prisma)
bun run db:push

# 3) داده نمونه (مربی، ۳ ورزشکار، ۱۰ حرکت، ۳ برنامه، تمرین‌ها، پیام‌ها، تراکنش‌ها)
bun scripts/seed.ts

# 4) اجرای سرور توسعه
bun run dev
```

## ✨ امکانات

### پنل مربی
- **داشبورد** — نمای کلی: تعداد ورزشکاران، برنامه‌های فعال، درآمد ماه، نرخ تبعیت هفته + نمودار تبعیت ورزشکاران
- **مدیریت ورزشکاران** — پروفایل کامل (قد، وزن، رشته، هدف، سطح، نکات پزشکی) + ایجاد حساب ورزشکار + صفحه جزئیات با نمودار وزن و سوابق
- **برنامه‌ساز تمرینی** — ساخت برنامه چند هفته‌ای، تعریف جلسات هفتگی، افزودن حرکات با ست/تکرار/وزن/استراحت و **ارسال برنامه به یک یا چند ورزشکار**
- **بانک حرکات** — حرکات با دسته‌بندی، گروه عضلانی، تجهیزات و **ویدئوی آموزشی** (آپارات/یوتیوب/mp4)
- **تقویم تمرین‌ها** — نمای هفتگی جلسات تمام ورزشکاران با پیمایش بین هفته‌ها
- **پیام‌رسانی** — چت مستقیم با هر ورزشکار + شمارنده پیام‌های خوانده‌نشده
- **مدیریت مالی** — ثبت شهریه/پرداختی‌ها + نمودار روند درآمد ۶ ماه + خلاصه وضعیت
- **گزارش عملکرد** — نرخ تبعیت، میانگین مدت و کیفیت تمرین، روند وزن، فعالیت ۸ هفته‌ای هر ورزشکار

### پنل ورزشکار
- داشبورد شخصی با آمار تبعیت تمرینی و وزن فعلی
- مشاهده برنامه تمرینی با جلسات هفتگی و جزئیات هر حرکت
- **ویدئوی آموزشی** برای هر حرکت
- **ثبت نتایج تمرین** (ست انجام‌شده، تکرار، وزنه) + کیفیت و مدت جلسه + یادداشت به مربی
- روند پیشرفت: نمودار وزن/چربی + ثبت اندازه‌گیری دوره‌ای
- سوابق کامل تمرین‌های قبلی
- چت با مربی

### عمومی
- کاملاً **فارسی و راست‌چین (RTL)** با فونت وزیرمتن و تاریخ شمسی
- **ریسپانسیو** — موبایل (نویگیشن پایین)، تبلت و دسکتاپ (سایدبار)
- احراز هویت امن با **سشن کوکی HttpOnly** و هش پسورد scrypt

## 🧱 معماری و تکنولوژی

| لایه | انتخاب | دلیل |
|-------|--------|------|
| فریم‌ورک | **Next.js 16 (App Router) + TypeScript** | SSR/SEO، API Routes یکپارچه، مسیر رشد به فول‌استک enterprise |
| UI | **Tailwind CSS 4 + shadcn/ui + Recharts** | سرعت توسعه، یکدستی دیزاین‌سیستم، چارت‌های سبک |
| دیتابیس | **Prisma ORM + SQLite** (نسخه دمو) | توسعه سریع؛ برای production فقط `provider` به PostgreSQL تغییر می‌کند |
| احراز هویت | سشن سمت سرور + کوکی HttpOnly | ساده، امن، بدون وابستگی خارجی؛ قابل مهاجرت به NextAuth |
| آیکون‌ها | Lucide | سبک و کامل |

```
src/
├── app/
│   ├── page.tsx              # SPA — ناوبری سمت کلاینت بین ویوها
│   └── api/                  # REST API (auth, coach, athlete, messages, payments)
├── components/
│   ├── app/coach/            # داشبورد، ورزشکاران، برنامه‌ساز، حرکات، تقویم، مالی، گزارش
│   ├── app/athlete/          # برنامه، ثبت نتایج، پیشرفت، سوابق
│   ├── app/shared/           # چت، ویدئوپلیر، کامپوننت‌های مشترک
│   └── ui/                   # shadcn/ui
├── lib/
│   ├── auth.ts               # سشن + هش پسورد
│   ├── client.ts             # fetch helper + فرمت تاریخ/عدد فارسی
│   └── db.ts                 # Prisma client
prisma/schema.prisma          # ۹ مدل: User, AthleteProfile, Exercise, Program,
                              # ProgramAssignment, WorkoutSession, SessionExercise,
                              # WorkoutLog/ExerciseLog, ProgressEntry, Message, Payment
```
